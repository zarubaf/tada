# Components and patterns

Under change by [ADR 0082](../adr/0082-redesign-of-the-web-client.md).

Screens use only the components in `apps/web/src/ui/` (ADR 0020).
This document lists the core components and the patterns for the main screens.
A new component needs an entry here in the same pull request.
The gallery (`apps/web/src/gallery/`) is a development tool that shows the components, does not ship, and may keep German literals outside Fluent.

## Core components

### Actions

| Component      | Variants                          | Rules                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------- | --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Button         | primary, secondary, quiet, danger | At most one primary button in a view. Labels are a verb and an object. The label does not wrap.                                                                                                                                                                                                                                                                                                                            |
| IconButton     | quiet                             | Only in toolbars and rows. `icon` and the required `label`: the label is the accessible name and the tooltip. The tooltip opens on hover and on keyboard focus; the button is not described by it, because it only repeats the name. 32 px; 44 px on a coarse pointer.                                                                                                                                                     |
| Link           | inline, standalone                | Inline links are underlined. A link never does what a button does.                                                                                                                                                                                                                                                                                                                                                         |
| LinkButton     | primary                           | A link in the style of a button. Only for an action that opens a page, for example a form.                                                                                                                                                                                                                                                                                                                                 |
| FileButton     | primary                           | A button that opens the file picker. It shows `isPending` while the upload runs and keeps focus.                                                                                                                                                                                                                                                                                                                           |
| FileLink       | secondary                         | A plain link to a file on the server, in the style of a button, for a download or a preview. The browser loads it.                                                                                                                                                                                                                                                                                                         |
| Menu           |                                   | For more than three secondary actions, or the member menu. The trigger is `dots-vertical` or a text.                                                                                                                                                                                                                                                                                                                       |
| MenuButton     |                                   | A menu whose trigger the caller draws, for example an avatar, a name with a chevron or an icon above a label. The shell uses it for the member menu, the event switcher and „Mehr“. An item can have an icon, a check mark for the current choice, a line above it and a disabled state.                                                                                                                                   |
| ChoiceButton   |                                   | A full-width button for one option of a choice, with a title and a detail line. For example the organization choice.                                                                                                                                                                                                                                                                                                       |
| CommandPalette |                                   | Opens from the command box of the top bar and with `Ctrl+K` or `⌘K`. A search field above a list of commands in a modal dialog. The typed text filters the commands; arrow keys move through the list while focus stays in the field; `Enter` runs the chosen command and `Esc` closes the palette. A live region announces the number of results. The shell loads it with the first opening. It has no record search yet. |
| ThemeToggle    | quiet                             | One button that cycles system, light and dark. By default it shows an icon and the current choice as its label. `iconOnly` shows the icon with a tooltip, as the top bar does. A live region announces each new choice. It follows a choice that another control makes, for example the command palette.                                                                                                                   |

Button sizes follow `--control-height-*` of the density. The primary button uses `--color-accent` and `--color-text-on-accent`.
The danger button is secondary in style with `--color-danger` text.
Row actions that remove or revoke something use the danger button.
The confirm button of a destructive confirmation also uses the danger button.

### Input

| Component                   | Rules                                                                                                                                                                                                                                                           |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TextField, TextArea         | Label above, help below, error below the help.                                                                                                                                                                                                                  |
| Select                      | For up to 7 options. More options use ComboBox. The variant `toolbar` has the look of the other controls of a toolbar (a button and a chevron icon) and is for filters; the default is the field of a form.                                                     |
| SearchField                 | A search field for the toolbar of a list: an icon, the input and a button that clears it. It has no visible label, so the accessible name is required, and a placeholder says what to type. The caller filters.                                                 |
| SearchSelect                | A select with a search field in its popover, for owner, workstream, milestone and similar lists. All options are present. An option can have an avatar. It has a required label, a „no result“ text, a check on the chosen option and an optional clear button. |
| ComboBox                    | Search in the options. Used for people, events and records.                                                                                                                                                                                                     |
| DatePicker, DateRangePicker | `de-CH` format; keyboard input and calendar. Shows the weekday.                                                                                                                                                                                                 |
| Checkbox, CheckboxGroup     | Label to the right of the box.                                                                                                                                                                                                                                  |
| RadioGroup                  | For two to five exclusive options that a member must see together.                                                                                                                                                                                              |
| Switch                      | Only for a setting that has an immediate effect. Not inside forms with a submit button.                                                                                                                                                                         |
| FileDrop                    | Drag and drop with a visible „Datei wählen“ button. Shows size limits before the upload.                                                                                                                                                                        |

### Display

| Component      | Rules                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| KnowledgeState | Shows the state of knowledge of a value (see [tokens.md](tokens.md)): the value, an icon and the label. An accepted value hides the label from the eye; `showLabel` shows it. Used in each place where a fact appears. Values come from `formatValue`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| StatusLabel    | Icon and text for a workflow status. `RecordStatusLabel` takes the kind and the status of any record and draws them from one table (`apps/web/src/work/recordStatus.ts`): the icon, the tone, the German word and the board column. A tone supports the text; a conditional commitment („bedingt“) has the warning tone. In a column of labels, `column` lets a label with a box hang to the left, so that all texts start at one edge.                                                                                                                                                                                                                                                                                                  |
| StatusIcon     | The icon of a status (open: dashed circle; in progress: half-filled circle; blocked: circle with a bar; done: circle with a check; canceled: circle with a cross; and one icon each for conditional, firm, superseded, mitigated and occurred, which is an octagon so that the triangle stays with a conflict). Status icons draw with the 1.5 px line of ADR 0021. The color comes from the tone. It has an accessible name (`label`) or stands next to the word of the status, never alone and never by color alone.                                                                                                                                                                                                                   |
| TypeIcon       | The icon of a record kind: „Aufgabe“, „Zusage“, „Meilenstein“, „Entscheid“, „Risiko“ (a flag, not the triangle of a conflict). It is an image with the kind as its name, or `decorative` when the name is next to it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Chip           | A small fact on a card or a row, 20 px high with 12 px text and a 12 px icon. Variants: `date` (takes `date`, `today` and `overdue`, formats the date, and adds the danger tone, another icon and the word „überfällig“ when the date is before today, unless `overdue={false}` says that the record is closed or the date is no due date; only this variant can be overdue), `workstream` („Bereich“), `proposal` (dashed square, violet, „Vorschlag“), `assumption`, `unknown` (labels and icons of KnowledgeState) and `neutral`. With `onPress` it is a button; its hit area, not the chip, grows to 44 px on a coarse pointer, and the chip keeps 12 px free above and below so that the hit areas of wrapped chips do not overlap. |
| Badge          | A count, for example waiting proposals. Never decorative.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Avatar         | Initials on one of six colors (`--color-avatar-1` to `-6`), chosen from the person ID or the name, in 20 or 24 px. The name is its accessible name; `decorative` hides it when the name is next to it. A photo only if the member uploads one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| RecordId       | `ACT-042` in `--font-family-mono` with tabular figures. A copy action comes with the side panel.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| RelativeTime   | „vor 2 Stunden“ with the exact time in a tooltip.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Kbd            | A keyboard key in hints and the shortcut list, in the monospace face, 20 px high.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Skeleton       | Gray blocks in the shape of the content. No shimmer animation with reduced motion.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| DataTable      | A read-only table with a caption, a header that sticks to the page, `--row-height` rows, and monospace or tabular columns where needed. Below 28rem of container width, each row is a two-line list row.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| LiveRegion     | A polite `status` or an assertive `alert` that is in the page before its text. Each screen has one of each; see [accessibility.md](accessibility.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Markdown       | Safe Markdown for text that members or agents write (ADR 0058): CommonMark with tables. Raw HTML is dropped, an image shows its alternative text only, and a link is `https` or `mailto` and opens in a new tab with `rel="noopener noreferrer"`. A `tada:` link is no address. Headings start at level 2 by default, because the page has the h1. A page that places the text deeper in its outline passes `headingLevel` (the level of `#`, at most h6), so that the headings of the text nest under the heading of the page.                                                                                                                                                                                                          |

Focus moves are not a component. The hooks `useFocusAfterCommit` and `useRetry` in `apps/web/src/ui/focus.ts` are the only way to move focus after an action.
See [accessibility.md](accessibility.md#focus).

### Navigation

| Component | Rules                                                                                                                                                                                                                   |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NavLink   | A navigation item. The current page has `aria-current="page"` and the current style. `icon` draws a Tabler icon before the label. `large` gives the bottom bar a thumb target.                                          |
| SubNav    | The sub-navigation of a template, for example of the settings or of an event. It contains NavLink items. `secondary` is a second row below one item, smaller and without a line, for example the registers of an event. |
| Toolbar   | The filter and display row above a list. One tab stop; arrow keys move between its buttons and menus.                                                                                                                   |
| SkipLink  | „Zum Inhalt springen“, the first focusable element of each page. It moves to `main`.                                                                                                                                    |

### Page

| Component | Rules                                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------------------------- |
| Page      | The `main` element of each template, with the page gutters. `width="form"` is the narrow column of the public page. |
| PageTitle | The `h1` of a page, in `--font-size-2xl`. Focus moves to it after a route change.                                   |

### Work board

These pieces belong to the „Arbeit“ page and live in `apps/web/src/work/`.

| Component    | Rules                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Board column | A region named by its `h2`: the icon of the status group, the title and the count of the shown records. The count is a number for the eye; the name of the heading reads „Offen, 4 Einträge“. The columns are „Offen“, „In Arbeit“, „Blockiert“ and „Erledigt“ in this order; „Abgebrochen“ is a rail that opens as a column; one button in its heading does both, keeps focus and has `aria-expanded` and `aria-controls`. The open state is the query key `canceled=1`. An empty column says „Keine Einträge“. Below 40rem there are no columns: a select with the counts picks the status group (the query key `column`; without it, the first group that has records) and one list shows it. The board has no drag and drop.                                                                                                                                                                                                      |
| Work card    | One record: the type icon, the readable ID and the owner avatar (24 px) in the first line; the title with at most two lines (the whole title is in the accessible name); then the chips: the status as icon and text, the date, and the workstream. The date is the due date of an action or a commitment, the date of a milestone and, for a decision, the day it was decided without an overdue state. A risk has no date. A closed record is never overdue. A redacted record shows „entfernt“ instead of the title. The card is one link to the record. Its name is the readable ID and the title (`aria-labelledby`); the kind, status, owner, date and workstream are its description (`aria-describedby`), each in its own element so that they read apart. A hover, a focus ring (`--color-focus`) and a border show that it is a link. A kind without a page (the risk) shows the same card as a named group without a link. |

### Containers

| Component   | Rules                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Panel       | A bordered area in the page flow. No shadow.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Sheet       | Opens from the right (medium, wide) or from the bottom (narrow). For modal tasks, for example filters. The details of a record use `SidePanel`.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Drawer      | A modal panel from the left edge for the navigation on narrow layouts. The page behind it is inert, focus stays inside and returns to the opener on close, and `Esc`, the close button and a press outside close it. It slides in unless the member reduces motion. The shell loads it with the first opening.                                                                                                                                                                                                                                                               |
| Dialog      | Only for a destructive confirmation or a blocking task. Title, one sentence, two buttons. `ConfirmDialog` is the confirmation; `TaskDialog` holds a blocking task with a field, for example the reason of „Verbindlich machen“.                                                                                                                                                                                                                                                                                                                                              |
| Popover     | For small forms and pickers that belong to one control.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Tooltip     | Text only, no interactive content. Opens on hover after 500 ms and at once on keyboard focus; the Escape key closes it. It repeats a name or adds a hint; no information lives only in a tooltip, because touch has no hover. IconButton uses it.                                                                                                                                                                                                                                                                                                                            |
| SidePanel   | The non-modal details of one record (ADR 0082). Docked beside the list from 80 rem, an overlay from the right from 40 rem, full screen below, where the page behind it is inert. Focus moves in on open and returns to the opener, else to the list, if it was still inside. `Esc` and the close button close it. It never traps focus. Pages load it lazily. Below 40 rem the panel makes everything outside it inert, except live regions and the toast region, and restores it on close. Use `Sheet` for a modal task dialog and `SidePanel` for the details of a record. |
| Tabs        | For two to six views of one record or list, each with a panel. Arrow keys move between the tabs. Not for navigation between pages and not for a filter.                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TypeFilter  | A row of pills that filters one list by type, with counts. One option is always chosen. An option can have an icon before its label. It is a group of toggle buttons, because it has no panels, and assistive technology announces it as a radio group. Arrow keys move between the options.                                                                                                                                                                                                                                                                                 |
| Banner      | A message for a whole page or the app, for example „Synchronisation seit 3 Stunden unterbrochen“. Cannot be hidden while the problem exists.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Toast       | Confirms the last action of the member, with an „Rückgängig“ action if possible. Never for errors that need an action.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| EmptyState  | A title, one sentence and one action, if the member can act there. No illustration.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| NoAccess    | The no-access state of an area: an EmptyState with „Sie haben keinen Zugriff auf diesen Bereich.“ and the roles that can give access.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| InlineError | A failed request in the area that failed: the message, the request ID and „Erneut versuchen“. `announce` sets how a screen reader learns of it.                                                                                                                                                                                                                                                                                                                                                                                                                              |

## Patterns for the main screens

### Portfolio (PM, desktop first)

- A table with one row for each event: name, dates, readiness, open exceptions, next milestone, lead.
- Readiness is a StatusLabel with a text, not a percentage ring.
- Exceptions (overdue, unowned, conflict, stale sync) appear as counts that link to the filtered register.
- The default sort is by the next milestone.
- Narrow layout: two-line rows; the exceptions move to the second line.

### Event overview

- A header with the event name, dates, place, the lead and the readiness. Each value has its KnowledgeState.
- Sections in this order: „Offene Fragen“, „Ausnahmen“, „nächste Meilensteine“, „Workstreams“ and „zuletzt geändert“.
- Unknown values show „Unbekannt“, never an empty space.
- „Was ist noch unbekannt?“ opens the Ask Event panel with this question.

### My Work (all members, mobile first)

- A list grouped by due date: „überfällig“, „heute“, „diese Woche“ and „später“.
- Each row: the RecordId, the title, the event, the due date and the StatusLabel.
- The row actions on narrow layouts: „Erledigt“, „Blockiert“, „Neues Datum vorschlagen“. These match the Telegram buttons.
- Items from several events appear in one list. The event name is visible in each row.

### Registers and tables

- A toolbar with: the search field (`/`), filters as chips, the view options and one primary action („Risiko erfassen“).
- The table has a sticky header, tabular numbers and a row height of `--row-height`.
- A click on a row opens the record in a sheet on medium and wide layouts, and as a page on narrow layouts.
- Bulk actions appear in the toolbar only when rows are selected.
- A filter that hides rows shows the count of hidden rows and a "Filter zurücksetzen" action.
- The registers of an event share this pattern: „Zusagen“, „Meilensteine“, „Entscheide“, „Risiken“, „Anforderungen“ and the actions.
  Each shows the status actions of its record in the sheet.
- „Meilensteine“ show the count of open actions and the two warnings (a late action, a past date).
- „Risiken“ sort by likelihood times impact, then by impact (ADR 0081).
- „Entscheide“ have no edit of the wording.
  „Ersetzen“ opens the create form for the new decision and supersedes the old one on save.

### Review Inbox („Eingang“)

- A list with detail. The list shows proposals that wait for the member, oldest first.
- The detail shows, from top to bottom:
  1. The proposed change as a comparison: the current accepted value and the proposed value.
  2. The source: the excerpt with the cited passage marked, the source version and the capture time.
  3. Conditions and assumptions of the proposal.
  4. The actions: „Annehmen“, „Bearbeiten und annehmen“, „Ablehnen“.
- If the target record changed after the proposal, the detail shows a conflict and disables „Annehmen“ with the reason.
- Keyboard: `J` and `K` move through the list; `A` accepts, `E` edits and `R` rejects, each with a visible hint.
- Batch review: a member can select several proposals of the same kind and accept them together after a summary.

### Evidence panel

- Shows the provenance of the selected value: the evidence links, the source versions, who accepted the value and when.
- Each source shows its freshness: „erfasst am 03.10.2026, 14:12“.
- A source that the member cannot see shows „Quelle nicht freigegeben“, never its content.
- Proposals and accepted values have separate sections, so the member never mixes them up.

### Forms

- One column, at most 40rem wide.
- Group related fields under a heading. No more than seven fields in a group.
- The actions are at the bottom: the primary action on the right on wide layouts, full width on narrow layouts.
- Leaving a form with unsaved changes asks for a confirmation. The web client does not do this yet.

### Empty, loading and error states

| State                   | Pattern                                                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Empty, first use        | EmptyState with one sentence about the purpose and the first action: „Noch keine Risiken erfasst. Risiko erfassen“.                              |
| Empty, after a filter   | „Keine Treffer für diese Filter.“ and "Filter zurücksetzen".                                                                                     |
| Loading, first load     | Skeleton rows in the shape of the content.                                                                                                       |
| Loading, refresh        | The old content stays; a small progress indicator appears in the toolbar.                                                                        |
| Error, a request failed | Inline message in the area that failed, with „Erneut versuchen“. The rest of the page stays usable.                                              |
| Error, no access        | NoAccess: „Sie haben keinen Zugriff auf diesen Bereich.“ and who can grant it. The client knows the roles, not the names, so it names the roles. |
| Stale data              | A Banner with the time of the last successful sync. tada never shows stale data as current.                                                      |
