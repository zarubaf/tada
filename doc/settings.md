# Settings

The command `tada settings` writes this file. Do not change it by hand.
Run `mise run gen` after a change of the settings code.

Settings come from environment variables (ADR 0025).
A variable that ends in `_FILE` gives the path of a file that contains a secret (ADR 0036).

| Variable                         | Value                            | Default                    | Secret | Commands                                                        | Description                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------- | -------------------------------- | -------------------------- | ------ | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `TADA_LOG`                       | log filter                       | `info`                     | no     | `serve`, `worker`, `telegram`, `migrate`, `bootstrap`, `export` | The level filter of the logs, in the syntax of `tracing-subscriber`, for example `info,tada_api=debug`.                                                                                                                                                                                                                                                                                                            |
| `TADA_DATABASE_URL`              | PostgreSQL URL                   | none                       | no     | `serve`, `worker`, `telegram`, `migrate`, `bootstrap`, `export` | The database URL without the password, for example `postgres://tada@db:5432/tada`.                                                                                                                                                                                                                                                                                                                                 |
| `TADA_DATABASE_PASSWORD_FILE`    | file path                        | none                       | yes    | `serve`, `worker`, `telegram`, `migrate`, `bootstrap`, `export` | The file that contains the database password.                                                                                                                                                                                                                                                                                                                                                                      |
| `TADA_PORT`                      | port number                      | `8080`                     | no     | `serve`                                                         | The TCP port of the HTTP server. The server does not handle TLS.                                                                                                                                                                                                                                                                                                                                                   |
| `TADA_TRUSTED_PROXIES`           | list of network ranges           | empty                      | no     | `serve`                                                         | The ranges of the reverse proxies, separated by commas, for example `10.0.0.0/8`. The server accepts `X-Forwarded-For` only from them, and logs their `X-Request-Id` as `proxy_request_id`. Set it if a reverse proxy is in front of tada: if it is empty, all clients have the address of the proxy and share one rate limit. The server writes a warning when a request from another peer has `X-Forwarded-For`. |
| `TADA_WEB_ROOT`                  | folder path                      | empty                      | no     | `serve`                                                         | The folder of the built web client. The image sets it. If it is empty, the server delivers the API only.                                                                                                                                                                                                                                                                                                           |
| `TADA_S3_ENDPOINT`               | URL                              | none                       | no     | `serve`, `export`                                               | The URL of the S3 API, for example `http://garage:3900`.                                                                                                                                                                                                                                                                                                                                                           |
| `TADA_S3_REGION`                 | text                             | none                       | no     | `serve`, `export`                                               | The S3 region. Garage uses the `s3_region` of its configuration.                                                                                                                                                                                                                                                                                                                                                   |
| `TADA_S3_BUCKET`                 | text                             | none                       | no     | `serve`, `export`                                               | The bucket for all objects of this installation.                                                                                                                                                                                                                                                                                                                                                                   |
| `TADA_S3_ACCESS_KEY_ID_FILE`     | file path                        | none                       | yes    | `serve`, `export`                                               | The file that contains the S3 access key ID.                                                                                                                                                                                                                                                                                                                                                                       |
| `TADA_S3_SECRET_ACCESS_KEY_FILE` | file path                        | none                       | yes    | `serve`, `export`                                               | The file that contains the S3 secret access key.                                                                                                                                                                                                                                                                                                                                                                   |
| `TADA_PUBLIC_URL`                | URL                              | none                       | no     | `serve`, `worker`, `bootstrap`                                  | The URL that members use, without a path, for example `https://tada.example.org`. All links in mails start with it.                                                                                                                                                                                                                                                                                                |
| `TADA_RATE_LIMIT_KEY_FILE`       | file path                        | none                       | yes    | `serve`                                                         | The file that contains the key of the rate-limit counters. The counters keep an HMAC of each address with it. All `serve` processes need the same key.                                                                                                                                                                                                                                                             |
| `TADA_UPLOAD_MAX_BYTES`          | byte count                       | `100000000`                | no     | `serve`                                                         | The largest file that one upload can have, in bytes. Only the upload routes accept a body of this size.                                                                                                                                                                                                                                                                                                            |
| `TADA_MAIL_FROM`                 | email address                    | none                       | no     | `worker`                                                        | The sender address of all mails that tada sends.                                                                                                                                                                                                                                                                                                                                                                   |
| `TADA_MAIL_SMTP_HOST`            | host name                        | none                       | no     | `worker`                                                        | The host name of the SMTP server. It must match the certificate of the server.                                                                                                                                                                                                                                                                                                                                     |
| `TADA_MAIL_SMTP_PORT`            | port number                      | `465`                      | no     | `worker`                                                        | The TCP port of the SMTP server. Use 465 for `implicit` TLS and 587 for `starttls`.                                                                                                                                                                                                                                                                                                                                |
| `TADA_MAIL_SMTP_USERNAME`        | text                             | empty                      | no     | `worker`                                                        | The user name for the SMTP server. If it is empty, tada sends without a login. Set it together with `TADA_MAIL_SMTP_PASSWORD_FILE`.                                                                                                                                                                                                                                                                                |
| `TADA_MAIL_SMTP_PASSWORD_FILE`   | file path                        | none                       | yes    | `worker`                                                        | The file that contains the SMTP password. Optional; set it together with `TADA_MAIL_SMTP_USERNAME`.                                                                                                                                                                                                                                                                                                                |
| `TADA_MAIL_SMTP_TLS`             | `implicit`, `starttls` or `none` | `implicit`                 | no     | `worker`                                                        | How tada secures the connection. `implicit` uses TLS from the start, and `starttls` requires an upgrade. `none` is only for a local development server; release builds reject it.                                                                                                                                                                                                                                  |
| `TADA_TELEGRAM_BOT_TOKEN_FILE`   | file path                        | none                       | yes    | `telegram`                                                      | The file that contains the token of the Telegram bot.                                                                                                                                                                                                                                                                                                                                                              |
| `TADA_TELEGRAM_API_URL`          | URL                              | `https://api.telegram.org` | no     | `telegram`                                                      | The base URL of the Telegram Bot API. Tests set a local fake.                                                                                                                                                                                                                                                                                                                                                      |
