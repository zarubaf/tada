# Data inventory

This file lists each category of personal data that tada stores (ADR 0045).
Each new table or column with personal data updates this file in the same pull request.
Logs hold no personal data (ADR 0035).

| Category                 | Table and columns                                                                | Purpose                                                                                                                          | Retention                                                                                                                                                            |
| ------------------------ | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Display name             | `app_user.display_name`                                                          | Shows the member to other members                                                                                                | While the user exists. Slice 1 has no user deletion.                                                                                                                 |
| Email address            | `email_identity.email`                                                           | Signs the member in and receives mail                                                                                            | While the user exists. Slice 1 has no user deletion.                                                                                                                 |
| Memberships              | `organization_membership`, `event_membership`                                    | Decide what a member can see and do                                                                                              | Until an owner or admin removes the membership.                                                                                                                      |
| Telegram user ID         | `telegram_identity.telegram_user_id`                                             | Links a Telegram account to a user                                                                                               | Until the link is removed. Slice 1 cannot remove a link.                                                                                                             |
| Telegram name            | `telegram_link_code.claimed_name`                                                | Shows the account to the member who confirms the link                                                                            | Until the code row is deleted. No job deletes it in Slice 1.                                                                                                         |
| Audit log (pseudonymous) | `audit_event.actor_id`, `principal_id`, `request_id`                             | Records who did what (ADR 0039). It holds IDs only.                                                                              | No deletion in Slice 1. A legal redaction keeps the IDs (ADR 0045).                                                                                                  |
| Invitation               | `invitation.email`, `invitation.display_name`, `invitation.invited_by`           | Sends the invitation, names the new member and records who invited                                                               | No deletion in Slice 1.                                                                                                                                              |
| Outbound intents         | `outbound_intent.user_id`, `invitation_id`, `request_id`                         | Records which message tada sent to whom and with what outcome (ADR 0042). It holds IDs only.                                     | No deletion in Slice 1.                                                                                                                                              |
| Sign-in tokens           | `magic_link.user_id`, `invitation_token.invitation_id`                           | Sign a user in or accept an invitation. The rows hold the token hash only (ADR 0008).                                            | Until the token is used. No job deletes expired rows in Slice 1.                                                                                                     |
| Sessions                 | `session.user_id`, `organization_id`, `created_at`, `last_used_at`, `user_agent` | Keep a member signed in, end idle sessions and record the browser of each session (ADR 0008). The rows hold the token hash only. | Until sign-out or revocation, or until the first request after the idle timeout (14 days) or the absolute timeout (90 days). No job deletes expired rows in Slice 1. |
| Rate-limit counters      | `rate_limit_counter.key`, `window_start`, `count`                                | Limit the sign-in requests for each address and IP address (ADR 0056). The key is an HMAC.                                       | One hour. Each sign-in request deletes the counters of ended windows.                                                                                                |
